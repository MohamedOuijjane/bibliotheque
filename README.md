# Bibliothèque

API REST de gestion de livres : CRUD, recherche, emprunt et retour.

**Stack :** Java 17, Spring Boot 3, Spring Data JPA, H2, Bean Validation

## Lancer

```bash
mvn spring-boot:run   # http://localhost:8080/api/livres
```

## Tester

```bash
mvn test
./tests-curl.sh       # ou importer postman/Bibliotheque.postman_collection.json
```
